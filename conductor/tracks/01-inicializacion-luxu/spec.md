# Spec: Inicialización Luxe Real Estate

## Objetivo
Establecer la base visual y estructural del proyecto, reemplazando el boilerplate de Next.js con una experiencia de lujo y configurando los componentes de UI necesarios.

## Alcance
- Instalación de componentes Shadcn UI críticos para un portal inmobiliario.
- Implementación de la Home Page (`src/app/page.tsx`) con diseño "Minimalist Luxury".
- Creación de componentes de diseño base (Header, Hero, Featured Grid).

## Componentes Shadcn a Instalar
- `card`: Para las fichas de propiedades.
- `input`: Para el buscador de la Hero section.
- `badge`: Para estados de propiedades (Vendido, Disponible).
- `navigation-menu`: Para la navegación principal.
- `separator`: Para la estructura visual.
- `button`: (Ya presente, verificar consistencia).

## Entregables
- Home page funcional con Hero Section y Grid de propiedades mockup.
- Estructura de componentes en `src/components/features/layout`.
- UI components instalados en `src/components/ui`.
