# Track 06: Property Detail & Lead Generation

## Goal
Create an immersive and high-converting property detail page. This page should showcase the property's luxury features through a sophisticated gallery, detailed specifications, and an elegant inquiry system to capture potential leads.

## Features
- **Immersive Gallery:** A high-end image carousel or masonry grid to showcase property visuals.
- **Detailed Specifications:** Elegant presentation of beds, baths, sqft, property type, and a full description.
- **Amenities List:** A clean, categorized grid of property features (Pool, Spa, Gym, etc.).
- **Agent Integration:** Display agent information (from `profiles`) linked to the property.
- **Inquiry Form:** A minimalist "Request a Viewing" form that persists inquiries to the `inquiries` table.
- **Location Context:** Static or interactive map placeholder reflecting the property's city and address.
- **Similar Properties:** A curated "You may also like" section at the bottom.

## Design Standards
- **Visual Hierarchy:** Large, high-quality hero imagery followed by clean, structured data.
- **Typography:** Serif for property titles and section headers; Sans for technical specs.
- **Interactivity:** Smooth transitions for the gallery and subtle hover states for form elements.
- **Minimalism:** Avoid clutter; use white space to emphasize the property's exclusivity.
